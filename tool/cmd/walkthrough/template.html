What this architecture map shows & how to use it

All Go packages in Librarian are grouped top-to-bottom across seven strict architectural tiers—from CLI Entry points and Command orchestration down to pure Infrastructure leaves (enforced by dependency_test.go). Click any package card to draw curved dependency wires: blue lines point downward to packages it directly imports, and emerald lines point from higher packages that import it. Click the selected card again (or Reset highlight) to un-dim all cards.
